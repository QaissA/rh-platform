# 1:1 Company Chat Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Let any signed-in Alizé user send persistent 1:1 messages to any other user, delivered live over WebSockets, with a Messages page and an unread badge.

**Architecture:** Conversations and messages in auth-service. REST through the existing JWT gateway. Action Cable on the api-gateway, identified by `?token=`. Auth-service publishes to Redis; the gateway cable process pushes to `chat:user:<id>`. Client writes only via REST so history does not depend on the socket.

**Tech Stack:** Rails 8, Action Cable, Redis 7, Angular 20, `@rails/actioncable`.

**Do not commit** unless the user asks. Rebuild `auth-service` and `api-gateway` after backend changes. Verify with request specs + `npx ng build`.

Design: `docs/plans/2026-09-08-user-chat-design.md`

**Step 2:** Models:

`backend/auth-service/app/models/conversation.rb`

```ruby
class Conversation < ApplicationRecord
  belongs_to :user_a, class_name: "User"
  belongs_to :user_b, class_name: "User"
  has_many :messages, dependent: :destroy

  validates :user_a_id, uniqueness: { scope: :user_b_id }
  validate :ordered_pair

  def self.pair_ids(id1, id2)
    [id1.to_i, id2.to_i].minmax
  end

  def self.find_or_create_pair!(user_id, other_id)
    a, b = pair_ids(user_id, other_id)
    find_or_create_by!(user_a_id: a, user_b_id: b)
  end

  def participant?(user_id)
    user_id.to_i == user_a_id || user_id.to_i == user_b_id
  end

  def other_user_id(user_id)
    user_id.to_i == user_a_id ? user_b_id : user_a_id
  end

  private

  def ordered_pair
    errors.add(:base, "user_a_id must be less than user_b_id") if user_a_id && user_b_id && user_a_id >= user_b_id
  end
end
```

`backend/auth-service/app/models/message.rb`

```ruby
class Message < ApplicationRecord
  MAX_BODY = 4_000

  belongs_to :conversation
  belongs_to :sender, class_name: "User"

  validates :body, presence: true, length: { maximum: MAX_BODY }
  validate :sender_is_participant

  private

  def sender_is_participant
    return if conversation&.participant?(sender_id)

    errors.add(:sender, "n’est pas participant")
  end
end
```

Add `has_many :conversations_as_a` / `as_b` on User only if needed; listing can query `Conversation.where("user_a_id = :id OR user_b_id = :id", id:)`.

```ruby
module Chat
  class Broadcast
    def self.message(message)
      payload = {
        type: "message",
        conversation_id: message.conversation_id,
        message: {
          id: message.id,
          sender_id: message.sender_id,
          body: message.body,
          created_at: message.created_at,
          read_at: message.read_at,
        },
      }
      [message.conversation.user_a_id, message.conversation.user_b_id].each do |uid|
        ActionCable.server.broadcast("chat:user:#{uid}", payload)
      end
    end
  end
end
```

`connection.rb`:

```ruby
module ApplicationCable
  class Connection < ActionCable::Connection::Base
    identified_by :current_user_id

    def connect
      claims = JsonWebToken.decode(request.params[:token].to_s)
      reject_unauthorized_connection unless claims && claims[:user_id]
      self.current_user_id = claims[:user_id].to_i
    end
  end
end
```

`chat_channel.rb`:

```ruby
class ChatChannel < ApplicationCable::Channel
  def subscribed
    stream_from "chat:user:#{current_user_id}"
  end
end
```
