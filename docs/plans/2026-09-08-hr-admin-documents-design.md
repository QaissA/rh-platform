# HR admin documents (templates)

When an employee requests an administrative paper, HR fills a template, saves it, prints from the browser, then marks it ready so the employee can download it in the app.

## Flow

1. Employee submits a request (`Documents`).
2. HR opens **Documents à traiter**, picks the request.
3. A template is prefilled (name, date, request note). HR edits the fields.
4. **Enregistrer** keeps a draft (`processing`).
5. **Imprimer** opens the browser print dialog.
6. **Mettre à disposition** sets `ready`. The employee can download/print the same document.

## Templates

- Attestation de travail
- Bulletin / attestation de salaire
- Attestation de congés
- Autre (free title + body)

## Delivery

- Print: browser print dialog
- Digital: in-app only (no email in this version)
